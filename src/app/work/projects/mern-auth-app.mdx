[mern-auth-app](https://github.com/mahenoorsalat/mern-auth-app) is a full-stack MERN authentication app with user login, registration, and JWT-based secure sessions.

## Role & Context
As **Full-Stack Engineer**, I built the auth flows end to end: React/Vite frontend, Express + Node.js API, and MongoDB user storage.

## What it covers
- Register / login with hashed passwords and JWT sessions
- Protected routes and auth middleware on the API
- MERN project structure (client + server) ready to extend

## Key Technologies
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express.js, JWT
- **Database**: MongoDB
