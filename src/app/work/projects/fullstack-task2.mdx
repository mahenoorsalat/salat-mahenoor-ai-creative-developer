[Job Executive](https://fullstack-task2.vercel.app) is a full-stack job platform with role-based auth: Job Seeker, Company, and Admin logins, plus registration flows.

## Role & Context
As **Full-Stack Engineer**, I built the auth system, role selection, and the job posting/search flows across frontend and backend.

## What it covers
- Role-based login (Seeker / Company / Admin) with quick demo access
- Registration and session handling
- Job posting and application flows

## Key Technologies
- **Frontend**: TypeScript, React / Next.js
- **Backend**: Node.js API
- **Deploy**: Vercel
