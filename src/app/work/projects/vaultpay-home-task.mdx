[VaultPay](https://github.com/mahenoorsalat/vaultpay-home-task) is an ERC20 escrow payment dApp running on a local Hardhat chain, with a React + Wagmi frontend.

## Role & Context
As **Full-Stack Engineer**, I implemented the escrow contract flow and the wallet-connected frontend: deposit, release, and refund states.

## What it covers
- Solidity escrow contract tested against local Hardhat network
- ERC20 approve / deposit / release / refund interactions
- React + Wagmi wallet connection and transaction states

## Key Technologies
- **Contracts**: Solidity, Hardhat
- **Frontend**: React, TypeScript, Wagmi
